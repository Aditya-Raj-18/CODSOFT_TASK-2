# CODSOFT-_-TASKSNO-2
A Java console application that calculates a student’s total marks, average percentage, and final grade. Users enter marks out of 100 for multiple subjects, and the program validates input before displaying results. Grades are assigned from A+ to F based on the calculated average percentage.

# Student Grade Calculator (Java)

CodSoft Task 2: a console application that calculates a student's total marks, average percentage, and grade.

## Features

- Accepts marks (out of 100) for any number of subjects
- Validates the subject count and each mark
- Calculates total marks and average percentage
- Assigns grades: A+ (90-100), A (80-89), B (70-79), C (60-69), D (50-59), F (below 50)

## Run

```powershell
javac StudentGradeCalculator.java
java StudentGradeCalculator
```
